# 出力の見本｜社員食堂の昼の混雑（数字はすべて架空）

## 1. 定義

- **決めてもらうこと**：時差昼休み（11:30開始と13:00開始の枠）を、全社で3か月試行することの可否
- **読み手と反論**
  - 総務部長「混んでいるのは月初や雨の日だけでは」
  - 人事部長「昼休みをずらすと、部署をまたぐ会議が組めなくなる」
  - 各部長「うちの部署は食堂に近いから関係ない」
- **目的・成果物・範囲**：経営会議で試行の可否を決めてもらう3〜6枚の資料。扱うのは昼の待ち時間と時差昼休みの効果。食堂の増築・メニュー変更は扱わない
- **場面と枚数**：月次の経営会議、持ち時間10分。本文6枚

## 2. 問いの分解

- 時差昼休みを全社で試行するか
  - 待ち時間は対策が要るほど大きいか
    - 全社でどれだけの時間を失っているか
    - 混雑は特定の日だけか、毎日か
  - 何が待ち時間を生んでいるか
    - 距離（フロア）か、来る時刻の集中か
  - 時差昼休みでどこまで縮むか
    - 何割が移れば、どこまで縮むか
  - 業務への影響は抑えられるか
    - 会議が組めなくなる問題をどう避けるか
  - どう試し、何で判断するか

## 4. タイトル列

1. 昼の待ち時間は全社で月1,900時間に達し、原因は12時台前半の集中にある
2. 混雑は特定の日ではなく、9月の20営業日すべてで起きている
3. 正午に会議が終わる部署は早めの部署の2.2倍待ち、フロア差は1.2倍だ
4. 時差昼休みに4割が移れば、平均の待ち時間は5.1分とほぼ半分になる
5. 定例会議を11:45に終える部署は、時差枠がなくても待ち時間が3割短い
6. 時差昼休みを3か月試行し、平均待ち時間が5分台に入れば全社で続けるべきだ

## 5. 点検の結果

- 反論3つ（数日だけでは／会議が組めない／近いから関係ない）に、No.2・No.5・No.3 がそれぞれ答えている
- No.5 は最初「会議の多い部署は、定例会議を11:45に終えれば時差枠を使わなくても待ち時間が縮む」で38.5字幅だった。根拠を「3割短い」に縮めて32字幅にした
- No.6 は最初「来月から3か月、4割を目標に…」で数字が3つあった。2つに減らした
- 未達：No.2 の日別の数字が素材に無い。会議の前に入退場ログから日別の値を出す必要がある
