# 工程1〜2｜問いを分解し、並べる

## 問いの分解（工程1）

- **頂点**は「決めてもらうこと」。例：時差昼休みを全社で試行するか
- **1段目**は、読み手が「はい」と言うために答えが要る問い。工程0の反論から作ると漏れない
  - 反論「混んでいるのは数日だけでは」→ 問い「混雑は常態か」
  - 反論「会議が組めなくなる」→ 問い「業務への影響はどこまでか」
  - 反論が無い問いでも、判断に必ず要るもの（なぜ必要か／何をするか／いくら・いつまでか／うまくいかなかったらどうするか）は足す
- **末端**は、1ページで答えられる大きさまで割る。1つの答えに2つ以上の主張が要るなら、まだ割れる
- 同じ段の問いは、同じ切り口で割る（「この段は何で割ったか」を1語で言える）。原因と打ち手のように切り口が違うものを同じ段に混ぜない

## 並べ方（工程2）

**1枚で1段だけ進める。** 主張を先に出して根拠を後ろに付けるのではなく、前のページを受けて次の1段を足す。「需要がある」「担い手が足りない」「費用がかさむ」「放っておくと負ける」を1枚に詰めず、1枚ずつ進める。ここでいう段は**話の段**であって、数字1つのことではない。同じ試行・同じ調査から出た複数の指標（入力時間・提出率・文字数など）は、同じ段なので1枚にまとめる。

**問題の次に、解消を置く。** 問題を示したページの後ろには、それを誰が何で解消するかのページを対で置く。問題だけを並べて終える資料は、読み手に宿題を渡すだけになる。

**リスクは対応策と同じページに置く。** リスクだけを列挙したページは作らない。

**並びの型**（迷ったときの出発点。合わなければ崩してよい）

| 場面 | 並び |
|---|---|
| 3〜4枚の決裁資料 | 結論（決めてほしいこと）→ 根拠（読み手の一番強い反論に答える）→ 打ち手か試算 |
| 提案書（5〜10枚） | 背景 → 問題 → 原因 → 打ち手 → 効果 → 進め方 → 決めてほしいこと |
| 登壇・ピッチ（7〜10分） | つかみ（製品の核を主語＋動詞の1文で）→ 会社紹介（1枚、題は素のラベル）→ 製品とは何か（定義文をタイトルに）→ なぜ作ったか（問題となぜ起きるか）→ 問題の裏にある価値 → 製品が回す仕組み → 事例（公表資料 → 現場の実例 → 効果試算。試算は「想定」と書く）→ ご提案・ご一緒したいこと（依頼）→ 付録（周辺事例・質疑用）。ピッチは説明資料ではないので、依頼から入らない。競合比較表は本編に載せず付録へ |
| 説明会（理解して行動してもらう） | 何が変わるか（変更前→変更後の表を1枚）→ なぜ変えるか（1枚まで）→ 変更点ごとに1枚（何が・いつから・自分は何をするか。よく来る質問はその変更点のページの右側で答える）→ 来月からの手順（申請の流れを時間の順に1本で。冒頭の変更一覧の言い直しにしない） |
| 報告（月次・進捗） | 結論（計画に対して今どこか）→ 全体（全部の区分）を1枚 → 計画からずれた区分と原因 → 次の期間の見込み → 相談したいこと（選択肢と、決めるのに要る材料） |

**10枚を超えたら、冒頭にまとめを置く。** 1枚目で全体の結論と要素を示し、後ろのページはその深掘りにする。まとめの各行は本文のタイトル列に対応させ（1行が本文1枚か1章）、深掘りのページには、まとめのどの要素を掘っているかを、まとめと一字一句同じ言葉で示す。10枚前後までなら章の扉もまとめのページも要らない。

**結論の位置。** 決裁会議・提案の場では、決めてほしいことを**1枚目**に置く（1枚目で答え、後ろで根拠、最後に条件と次の段取り）。決裁者は最初に「何を決めるのか」を知りたい。1枚目で結論を示した後も、本文の中は1段ずつ積む（各ページで主張を先に言い切って根拠を後付けしない）。登壇・ピッチは上の並びに従い、依頼は最後に置く。説明会や勉強会のように、聞き手がまだ問いを持っていない場面も、問いから入って答えに進む。

**自社の語りは控えめに。** 自社について語るタイトルは、事実で裏付く範囲まで控えめに書く。会社紹介と章の入口のページは、主張文でなく素のラベル題（「会社紹介」）でよい。

**反論には中身で答える。** 反論ごとに、中身そのものに答える行を用意する。枚数を絞る必要があるときは、性質の近い反論を1枚の表（指摘／分かっていること／対応案）にまとめてよい（タイトルは「〜で応える」のような予告ではなく、答えの中身を言う）。答えが素材に無い反論は、無理に別の話で埋めず、確認事項に回す。答えの無い反論が複数あるときは、反論ごとにページを作らず、「分かっていること／まだ分かっていないこと／いつまでに誰が確かめるか」の1枚にまとめる。

**最大の懸念には一番厚く答える。** 読み手の懸念のうち一番重いもの（「優秀な人を落とさないか」など）には、1枚以上と長めの時間を割く。軽い懸念と同じ1枚に詰めない。

**逆の選択肢の利点を受け止める。** 推奨と逆の選択肢（導入しない／導入する）にも勝っている点があるなら、比較の表で正直に示したうえで推奨を言う。片方の利点しか載せない資料は「結論ありき」と突かれる。

**社外向けの資料では、相手の不安を先に潰す順にする。** 顧客・取引先への提案では、相手の懸念（場所・利益・前例）に答えるページを、依頼のページより前に置く。「分からない」は相手に見せるページにせず、確認のお願い（「12店の置き場所を一緒に確認したい」）の形にする。

## 枚数の目安

| 場面 | 目安 |
|---|---|
| 決裁会議・経営会議 | 1枚あたり1.5〜2.5分（10分なら4〜6枚） |
| 登壇 | 1枚40秒前後（7分なら8〜10枚）。問題のパートは2枚まで |
| 説明会 | 1枚2〜3分（20分なら表紙を除き6〜8枚）。背景や統計は1枚まで。質疑の時間を別に取る |
| 報告 | 1枚2〜3分。相談事項があるときは、持ち時間の半分ほどを議論に残す |
| 背景が分からない依頼 | 1枚の論点整理だけ（SKILL.md 工程0）。デッキにしない |

枚数を削るときは、章扉・目次 → まとめと重なる本文 → 補足・付録 の順に削る。結論のページとまとめは残す。

**質疑用の付録。** 「聞かれそうな質問」のうち本編で答えない質問は、質疑用の付録に回してよい（枚数の上限には数えない）。本編の流れを止めて質問に答えるページを挟まない。

**背景を先に置く。** 変更点や打ち手と、その理由になる数字（差し戻し理由など）の対応は、打ち手を説明する前に示す。打ち手の説明が終わった後で統計に戻らない。

## 見せ方の選び方

| 言いたいこと | 見せ方 |
|---|---|
| 時間とともにどう変わったか | 時系列（縦棒・折れ線）。2時点でも前後の棒にする |
| 全体のうち何がどれだけか | 構成比（全体が1つなら円、複数の全体を比べるなら積み上げ棒） |
| 項目どうしの大小・順位 | 項目比較（横棒。降順に並べ、強調は1本だけ） |
| ばらつき・偏り | 分布（縦棒のヒストグラム） |
| AとBが連動しているか | 相関（散布図） |
| 複数の対象を複数の観点で比べる | 軸のある表（行＝対象、列＝観点） |
| 何から何へ、どの順で（順序のある工程・時間） | 矢羽。順序の無い並列の項目（変更点が3つ、など）には使わず、表にする |
| 前提からどう結論が出るか | 前提→帰結の2カラム |
| 1つの大きな数字が主役 | 数値カード（数字＋短い説明） |
| 増減の内訳（何が増やし、何が減らしたか） | 滝（ブリッジ） |

推移・構成比・分布・相関は、表に数字を並べて済ませない。図にする。

ページの形は、まず基本形（①表 ②左に前提・右に意味合い ③左右の対比 ④左に分析・右に解説）に当てはめ、当てはまらないときだけ応用形（矢羽・ロードマップ・Before→After・2×2・ピラミッド・ウォーターフォール・ファネルなど）を使う。1ページに1つの比較・1つの強調・1つの意味合い。
