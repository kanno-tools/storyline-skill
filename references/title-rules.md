# 工程2〜3｜タイトルの書き方

ストーリーラインのタイトルは、そのままスライドのタイトルになる。**タイトルだけを上から読んで、話が1本通ること**がすべての基準。

## 条件

- **主語と述語のある文で、常体で書く。** 「です」「ます」で終えない
- **読み手が社外（顧客・取引先）のときは、相手に指図する言い方をしない。** 「〜すべきだ」は使わず、「〜を提案する」「〜を実施したい」「〜で〜が見込める」と書く。社内の決裁でも、決裁者への依頼は「〜したい」「〜を承認してほしい」の形が自然なことが多い
- **役割ごとに書き分ける**
  - 主張・打ち手・決めてほしいこと：事実＋判断を1文に持つ。判断語の例：〜すべきだ／〜に限られる／〜に値する／〜を左右しない／〜ではなく〜だ／〜が見込める／〜できる／〜が必要だ
  - 前提・事実：事実を言い切る文でよい。ただし「何が分かったか」まで書き、題名（「〜の分析」）で済ませない
  - **相関しか無いデータの行は、役割を「事実」にし、判断語を付けない。** 「Aの多い人はBも多い」までを書き、「AがBを増やす」とは書かない。判断は、因果を確かめた後の行か、決めてほしいことの行で言う
- **1行に収める。目安は36字幅**（全角換算、半角英数字・記号は0.5字）。入らないときは、根拠の部分を見せ方や図の題に回す。**主語・対象・固有名詞を削って圧縮しない**
- **そのページだけを見た初見の人に意味が通ること。** 「この」「その」「前述の」で他のページを指さない
- **母数・出所・調査期間はタイトルに入れず、根拠の列に書く。** 時点は、それ自体が主張の核のとき（「2年で半減」）だけ書く
- **数字は、主張の核になるものだけを1文に2つまで。** 要素の個数は書かない（「3つの理由」「5段階」は主張ではない）。個数を書きたくなったら、中身の結論を書く
- **問いの形のタイトルも、文として完結させる。** 「〜の扱いは」で止めず、「〜はどう扱うか」と書く。ただし、質問に答えるページ（よくある質問など）のタイトルは問いではなく答えを書く。答えが素材に無ければ、そのページは確認事項に回す
- **伝聞・見込みは、言い切らない。** 「バイヤー談」「営業の積み上げ」「ベンダー資料」が根拠の数字は、タイトルで「〜によると」「〜の見込みでは」と出所の種類を示す
- **母集団が同じかどうか分からない2つの数字を、「別の集団」「同じ集団」と断定しない。** 分からないなら確認事項にする
- **数字には単位と期間を付ける。** 「申請4,200件」ではなく「月4,200件の申請」
- **解釈をタイトルで言い切らない。** 数字の対応づけや読み方が依頼者側の解釈（素材に書かれていない）なら、タイトルは事実までにし、解釈は確認事項に回す
- **素材で確かめられていない事実は、タイトルで向きを決めない。** 素材が「増えた気がする」程度なら「残業は前期から増えた（要確認）」と書かず、「残業は前期と比べてどう変わったか」と問いの形にするか、確かめる行として「分かっていること／まだ分かっていないこと」の1枚に入れる
- **変化を言うタイトルは、前と後の両方の値（か比べる相手）を入れる。** 「5分に収まった」だけでは改善の大きさが伝わらない
- **試算・推定・提案は、前提をタイトルに入れる。** 「試行と同じ効果が出れば、月317万円分の時間が空く」のように条件を書く。条件を外すと確定値に見える
- **母集団の違う数字を、同じ集団の変化として書かない。** 「調査（60名）の平均14分」と「試行（18名）の中央値5分」を「18名で14分から5分に縮んだ」とは書かない。「試行では1件5分（中央値）で、調査の平均14分を大きく下回る」のように、別の数字だと分かる形にする
- **言い過ぎない。** 根拠の列の数字で裏付けられる範囲まで主張を縮める。逆に、狭く書きすぎて事実より弱くもしない
- **「誰から見て」を明示する。** 外部・社内・現場・当社のような相対語は、主体を名指しする
- **話題のラベルを頭に付けない。** 「現状と課題：〜」「推進体制：〜」は目次に見えるだけ。コロンの後ろに主張があるなら、前のラベルを消す

## 禁止の形

| 禁止 | なぜ | 直し方 |
|---|---|---|
| 「A。B」の二段構え | 判断がどちらか分からない | 「〜のため」「〜だが」「〜ことで」で1文にする |
| 数え上げ（「課題は3つ」） | 判断が無い | 3つのうち何が効くかを言う |
| 題名・体言止め（「〜の現状」） | 判断語が消える | 述語を付ける |
| 話題ラベルの前置き（「現状：〜」） | 通し読みが目次になる | ラベルを消す |
| ダッシュ（「——」「—」） | 文が切れる | 読点か接続語 |
| 自己言及（「本ページでは」） | 資料の外から見た言い方 | 中身を言う |
| 圧縮語（「精度向上」「連携強化」） | 誰が何をするか読めない | 主語と動詞のある文にする |

## 文型を散らす（隣り合う3枚で同じ形を続けない）

- 因果「〜のため、〜する」
- 条件「〜すれば、〜が見込める」
- 逆接「〜だが、問題は〜にある」
- 起因「〜を左右するのは〜ではなく〜だ」
- 評価「〜は〜の範囲にあり、〜を左右しない」
- 提言「〜に、〜を集中させるべきだ」

1本の資料で同じ文型が6割を超えたら、主張ではなく型をなぞっている疑いがある。

## 書く順番

1. このページはどの問いに答えるか（工程1の末端）
2. 答え（判断）を一言で
3. 支える事実を1つ
4. 2と3を接続語で1文にする
5. 36字幅を超えたら、根拠の部分から削って見せ方に回す。判断語と接続語は削らない

**逆テスト**：図だけを見た人が同じ文を書けるなら、判断が足りない。
