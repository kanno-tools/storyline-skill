# 検証の記録（v1.1.0 → v2.1.0、2026-10-08）

## 何と比べたか

元にした consulting-pptx-skill（手順1「作る前の定義」と手順2「ストーリーライン」だけを実行させたもの）と、このスキルを、同じ素材で比べた。

- **作る側**：文脈を持たない別のエージェント（Claude Sonnet）が、それぞれのスキルの指示だけを読んで成果物を作る
- **審査する側**：作り手もスキルの存在も知らない別のエージェント（Claude Opus）が、素材と2つの成果物を X・Y として読み比べ、7観点×10点で採点する。X・Y の割り当ては毎回入れ替えた
- 7観点：次に動けるか／目的に足るか／反論・疑問への備え／根拠との整合／話の通り／日本語と明快さ／量と粒度

## 素材（すべて架空）

| No | 場面 | 種類 |
|---|---|---|
| m1 | 営業日報の音声入力を全営業所へ広げるか（部長会10分） | 社内の決裁 |
| m2 | 地方スーパーへの販促企画の提案（商談30分） | 社外の提案 |
| m3 | 来期のチーム目標（背景がほとんど無いメモ） | 背景不足 |
| m4 | 社内ビジネスコンテストの登壇（7分） | 登壇・予算申請 |
| m5 | 経費精算ルール変更の説明会（20分・300名） | 説明会 |
| m6 | 9月の月次報告と相談（15分） | 報告 |
| m7 | 新卒採用にAI面接を入れるか（承認会議20分） | 社内の決裁・データが割れる |
| m8 | 取引先への値上げのお願い（面談45分） | 社外の交渉 |
| m9 | 基幹システム移行の遅延報告と追加予算（経営会議20分） | 報告＋選択 |

m4〜m9 は、最初に使うときまで規則の改善に一度も使っていない素材（保留素材）として、順に追加した。

## 負けから直した主なこと

- 決裁・提案では依頼を1枚目に置き、最後は依頼の念押しか段取りで締める（「まだ分からないこと」で終えない）
- 母集団・統計量の違う数字を、同じ集団の変化として書かない。伝聞・見込みは言い切らない
- 反論には中身で答える。答えが素材に無ければ確認事項に回し、「未確認」のページを2枚以上作らない
- 選択を求めるときは、推奨しない側が勝つ軸と隠れた費用まで含めた比較の行を置く
- 依頼者が指定した依頼は変えない。依頼は1つにまとめる
- 説明会・報告の並びと枚数の目安を足した
- 背景が足りないときも、選択肢と、素材で埋めた1枚の論点整理を出す
- 成果物に作業の経緯・スキルの用語を書かない

## 限界

- 作る側は Claude Sonnet で検証した。会社 VM の Gemini で同じ品質が出るかは未確認
- 審査も AI で、人の審査ではない。素材も架空

## v2.1.0：元のスキル自身の基準での検証と、規則の差し戻し

### v2.0.0 までの検証の弱点
v2.0.0 までの審査基準（7観点）は Claude が自分で書いたもので、規則の改善もその審査の指摘だけを元にしていた。そのため、コンサルの知見ではなく AI 審査役の好みに合わせて規則を変えた恐れがあった。

### やったこと
1. **規則の突き合わせ**：storyline の規則を、元の slide-rules.md 全文と1つずつ照らした。一致 約38件、追加、元と逆 12件、元にあって落とした 14件。主なものは原文で裏を取った
2. **元に差し戻した**（食い違いは原則として元の規約に合わせた）
   - タイトルは1行・約40字が基本、長ければ意味の切れ目で2行可（§2.1）。根拠は図の題ではなく軸タイトルか本文へ（§3）
   - 体言止めは可。禁止するのは判断の無い題名だけ（§2.2）
   - 登壇・ピッチの並びは §9.3（つかみ→会社紹介→製品とは→なぜ→価値→仕組み→事例→ご提案）。依頼から入らない
   - 1枚目で結論を示しても、本文は1段ずつ積む（§4.44）
   - 背景が分からない依頼は、デッキにせず1枚の論点整理だけ（§0）
   - 第三者の確認は必須、1ラリーで止めて依頼者に聞く。採否表は別添で渡す（§8）。確認には根拠の数字まで渡す
   - 見せ方は基本形を優先、項目比較は横棒、構成比は円（複数を比べるなら積み上げ棒）、2時点でも図（§5.11・§5.12）
   - 下書きか提出版かを確認（§0）、自社の語りは控えめ・会社紹介はラベル題（§2.15・§2.16）、まとめと深掘りの言葉を一字一句そろえる（§4.33）、同じ軸で検証（§4.42）、人のレビューを勧める（§7.15）
3. **元のスキル自身のレビュー指示文（content-review-prompt.md）の採点軸で審査し直した**：版面の質を除く6軸×10点。素材ごとに審査役3体（Claude Opus）、X・Y の割り当てを入れ替え、多数決

### 読み方
- 元の基準で測っても、合計では storyline が上回る。ただし差は小さく、素材によって勝ち負けが入れ替わる幅の中にある
- **元のスキルの方が良い場面**：説明会（m5）。背景不足（m3）と遅延報告（m9）はほぼ互角
- storyline の強み（審査役の指摘から）：想定質問の列、根拠の数字の母集団・統計量の扱い、確認事項と「答えでどの行が変わるか」、反論への備え
- 規則を元に戻した結果、月次報告（m6）と登壇（m4）は大きく良くなった

- 素材は架空の9件だけ
